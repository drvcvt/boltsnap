# Boltsnap Tray Icon Implementation Plan

> **For agentic workers:** Implement this plan task-by-task — one task per commit, run each task's test before moving on. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the missing `camera-video` theme icon with the accepted Boltsnap mark embedded as tray pixmaps.

**Architecture:** Convert the approved raster into transparent 32 px and 64 px PNG assets. Decode them once with the already-installed `image` crate, convert RGBA bytes to the ARGB byte order required by `ksni`, and return cloned `ksni::Icon` values from the tray implementation.

**Tech Stack:** Rust 2024, `ksni` 0.3.5, existing `image` 0.25 dependency, ImageMagick for deterministic asset conversion.

```rust
fn tray_icons() -> &'static [ksni::Icon] {
    static ICONS: std::sync::LazyLock<Vec<ksni::Icon>> = std::sync::LazyLock::new(|| {
        [include_bytes!("../assets/icons/boltsnap-tray-32.png").as_slice(),
         include_bytes!("../assets/icons/boltsnap-tray-64.png").as_slice()]
            .into_iter()
            .map(|png| {
                let image = image::load_from_memory_with_format(png, image::ImageFormat::Png)
                    .expect("embedded Boltsnap tray icon must be valid PNG");
                let mut data = image.to_rgba8().into_raw();
                for pixel in data.chunks_exact_mut(4) {
                    pixel.rotate_right(1);
                }
                ksni::Icon {
                    width: image.width() as i32,
                    height: image.height() as i32,
                    data,
                }
            })
            .collect()
    });
    ICONS.as_slice()
}
```
